## 收录标准(以后更新资源时遵守)

- 优先官方文档;其次社区公认经典(star 数、被引用次数)
- 注明每个来源"适合什么场景"(入门 / 规范 / 找灵感)
- 链接失效时更新,不保留死链

## 综合时要注意的要点(预判)

1. **读者视角**:README 给"第一次看到项目的人"看,回答"这是什么、能用吗、怎么用"
2. **分层**:一句话简介 → 快速开始 → 详细文档链接,不要把所有内容塞进 README
3. **与 AGENTS.md 分工**:README 面向人类使用者;AGENTS.md 面向 AI 维护者
4. **用真实示例**:像 awesome-readme 里收集的,比抽象规则有说服力
